# Структура проекта и данных

## Папка проекта

```text
SandinFinance/
├─ SandinFinance.slnx          открыть проект в IDE
├─ README.md                  возможности и запуск
├─ assets/
│  ├─ branding/               логотип PNG и значок ICO
│  └─ merchant-icons/         готовые иконки магазинов
├─ src/                       код приложения и финансовая логика
├─ tests/                     автоматические проверки
├─ scripts/                   запуск, подготовка Windows, обновление значка
│  └─ SandinFinance.Maintenance/ служебные операции с профилем
├─ docs/                      документация
└─ .local/                    локальные скриншоты и файлы проверок, скрыта и не в Git
```

Готовые иконки встроены в приложение. Для «Пятёрочки», SPAR, «ВкусВилла», «Самоката», «Столичек» и других известных магазинов изображение подставляется по названию. Кнопка «PNG…» открывает галерею готовых иконок и позволяет загрузить собственное изображение. Пользовательская PNG имеет приоритет над готовой.

## Профиль в Документах

```text
Документы/SandinFinance/Sandin/
├─ profile.json               имя и параметры входа
├─ data/
│  ├─ accounts.json           счета и операции
│  ├─ categories.json         категории и пользовательские иконки
│  └─ recurring-payments.json расписания и отметки оплаты
└─ backups/
   ├─ automatic/              последняя резервная копия каждого файла
   └─ manual/                 снимки перед служебными исправлениями и переносами
```

При открытии старого профиля файлы автоматически переносятся в эту структуру. Старые данные и PIN сохраняются. Различающиеся копии не перезаписываются: приложение сообщает о конфликте. Папка из старого LocalAppData при первоначальном импорте остаётся нетронутой.

Автоматические копии имеют фиксированные имена и не размножаются при каждом сохранении. Excel сохраняется только в выбранную пользователем папку, а временный файл удаляется после завершения или ошибки экспорта.

## Настройки и Excel

Нажмите имя профиля → «Настройки». Здесь доступны смена PIN, открытие папки профиля и «Экспортировать в Excel». После нажатия открывается диалог выбора места сохранения `.xlsx`.

В книге один лист «Расходы»: дата, время, счёт, категория, магазин/место и сумма в рублях. Вверху — число операций и итог, в таблице — фильтры, закреплённые заголовки и числовые даты/суммы. Экспорт охватывает все даты действующих и скрытых счетов. Удалённые счета, доходы, переводы и автоматические проценты не входят в таблицу расходов. PIN и файлы профиля в Excel не попадают. Установка Microsoft Excel для выгрузки не требуется.

## Служебные команды

Команды обслуживания отделены от тестов. Применять их следует с закрытым приложением и только к нужной папке профиля. Перед изменениями создаётся снимок в `backups/manual`.

Для переноса старого профиля:

```powershell
dotnet run --project scripts/SandinFinance.Maintenance -- --organize-profile "<Документы>\SandinFinance\<имя профиля>"
```

Остальные команды предназначены для точечных исправлений истории; пользовательские суммы, GUID и PIN не хранятся в исходниках. Обычная работа с бюджетом выполняется в приложении.
