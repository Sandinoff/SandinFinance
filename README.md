# SandinFinance

Личный бюджет для Windows x64: счета, расходы, доходы и кредитные долги.

## Изменения в 0.2.1

- Папка данных определяется для текущего пользователя Windows, включая перенаправленные «Документы».
- В настройках можно выбрать другую папку. Профиль, PIN, операции и резервные копии копируются с проверкой; исходная копия сохраняется.
- Выбранное место запоминается между запусками. Недоступный диск не заменяется пустым бюджетом.
- Документация и примеры установки не содержат персональных путей.

## Запуск

Скачайте `SandinFinance.exe` из [последнего релиза](https://github.com/Sandinoff/SandinFinance/releases/latest). Отдельная установка .NET не нужна.

При первом запуске укажите имя, создайте и подтвердите PIN из четырёх цифр. Далее вход выполняется по PIN.

Данные по умолчанию: «Документы» текущего пользователя → `SandinFinance/<имя профиля>`. Имя профиля задаётся внутри приложения и не обязано совпадать с именем учётной записи Windows. Изменить расположение: имя профиля → «Настройки» → «Изменить папку».

## Возможности

- Счета, остатки, переводы и настраиваемые кредитные периоды.
- Расходы и доходы с категориями, магазинами и 13 встроенными PNG-иконками.
- Диаграмма, фильтры по датам и экспорт расходов в Excel.
- Накопительные проценты, временные ставки и уточнение фактических выплат.
- Регулярные платежи и напоминания за три дня.

Профили, PIN, финансовые данные, выбранные пути и резервные копии хранятся локально и исключены из Git и готового приложения. PIN защищает вход; сами файлы бюджета не зашифрованы.

## Разработка

Требуются Windows и .NET SDK 10.

```powershell
dotnet build SandinFinance.slnx -c Release
dotnet run --project tests/SandinFinance.Checks -c Release
dotnet run --project tests/SandinFinance.UiChecks -c Release
powershell -ExecutionPolicy Bypass -File scripts/publish-windows.ps1
```

Последняя команда создаёт `SandinFinance.exe` в корне проекта. [Структура данных](docs/project-layout.md) · [Установка исходников](docs/windows-setup.md).
