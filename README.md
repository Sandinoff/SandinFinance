# SandinFinance

Будущее настольное приложение для учёта личного бюджета.

Проект находится на этапе подготовки. Интерфейс и финансовая логика ещё не реализованы; стек и подробное ТЗ пока не выбраны.

## Идея

- Создаваемые пользователем источники денег: наличные, дебетовые и кредитные карты, накопительные счета; начальные остатки.
- Расходы с выбором источника, даты и времени, категории и названия магазина.
- Общий остаток, задолженность по кредитным картам и круговая диаграмма расходов.
- Проценты по накопительным счетам и сроки платежей для беспроцентного периода кредитных карт.

Правила расчёта процентов и кредитных периодов уточним перед реализацией.

## Работа с проектом

Облачная копия: `/workspace/SandinFinance`.

Папка на Windows: `<папка проектов>\SandinFinance`.
Подготовка локальной копии описана в [docs/windows-setup.md](docs/windows-setup.md).

Зависимостей, команды запуска и тестов приложения пока нет. Сейчас репозиторий содержит документацию и вспомогательный скрипт.

## Сохранение

GitHub хранит историю исходного кода после `git commit` и `git push`.
Базы с финансовыми операциями, секреты и локальные резервные копии исключены из Git.
Резервное копирование пользовательских данных нужно спроектировать отдельно.

Репозиторий должен быть Private; его видимость проверяется в настройках GitHub.
