# Manrope

Источник: [Google Fonts — Manrope](https://github.com/google/fonts/tree/main/ofl/manrope).
Лицензия SIL Open Font License 1.1 находится в `OFL.txt` и поставляется с приложением.

`Manrope-Variable.ttf` — исходный шрифт. Для WPF из него подготовлены статические
начертания Regular (400), SemiBold (600) и Bold (700), встроенные в ресурсы приложения.
Шрифт включает кириллицу и знак рубля; установка в Windows не требуется.
